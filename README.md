# PlayMap — პატარა თავგადასავლები, დიდი მოგონებები

ბათუმის ოჯახებისთვის განკუთვნილი ვებ-პლატფორმა, სადაც მშობლებს შეუძლიათ იპოვონ ბავშვებისთვის შესაფერისი ადგილები: პარკები, სათამაშო ცენტრები, თეატრები, ზოოპარკი, აკვარიუმი და სხვა.

## გაშვება

```
npm install
npm run dev
```

გახსენი ბრაუზერში ის მისამართი, რასაც ტერმინალი აჩვენებს (ჩვეულებრივ http://localhost:5173).

საბოლოო ვერსიის ასაგებად:

```
npm run build
npm run preview
```

აგებული ფაილები `dist/` საქაღალდეში ჩნდება.

## ფუნქციები

- ადგილების ძებნა სახელით
- ფილტრები კატეგორიის მიხედვით
- „ჩემთან ახლოს“ — 5 კმ რადიუსში მყოფი ადგილები
- რჩეულების შენახვა (ინახება ბრაუზერში)
- ოჯახური დღის დამგეგმავი ასაკის, ამინდის, ბიუჯეტისა და დროის მიხედვით
- ტურისტების სექცია ბათუმში ჩამოსული ოჯახებისთვის
- გვერდი „რჩეულები“ (`#/favorites`): გულით შენახული ადგილები ერთ ადგილას, წაშლით ან მთლიანად გასუფთავებით
- ფილტრები ასაკის, სივრცის (ღია/დახურული) და ფასის მიხედვით; ტურისტების სექციაში სწრაფი ბმულები (წვიმიანი დღე, უფასო ადგილები, ცხოველები)
- ამინდი ბათუმში (მიმდინარე და 5 დღის პროგნოზი, Open-Meteo) ერთი ღილაკით შესაბამისი ადგილების ჩვენებით
- ორი ენა: ქართული და ინგლისური (ღილაკი „EN / ქარ“ ზედა მენიუში, არჩევანი ინახება ბრაუზერში)
- ტელეფონის მენიუ და „ჩვენს შესახებ“ სექცია
- რუკა (Leaflet + OpenStreetMap): ჩანს ის ადგილები, რაც ფილტრებს ემთხვევა
- ბარათზე „დეტალები და მისამართი“: მისამართი, საათები, ტელეფონი და Google Maps-ის ბმული

```

  App.jsx             მთავარი კომპონენტი და საერთო მდგომარეობა
  utils.js            ფილტრაცია, მანძილის გამოთვლა, რჩეულები
  i18n.js             ენის გადართვა და ადგილების თარგმნა
  weather.js          ამინდის კოდები და მისამართი
  data/
    places.js         ყველა ადგილის მონაცემი
    categories.js     კატეგორიები და ფილტრები (ორ ენაზე)
    ui.js             ინტერფეისის ტექსტები ქართულად და ინგლისურად
    placesEn.js       ადგილების ინგლისური ტექსტები
  components/         Header, Hero, Categories, Explore, LocationSearch,
                      MapView, PlaceCard, PlaceModal, Favorites, Tourist,

```

## ახალი ადგილის დამატება

გახსენი `src/data/places.js`, დააკოპირე ერთ-ერთი ობიექტი, შეცვალე მონაცემები და სურათი ჩააგდე `public/images/` საქაღალდეში. `image` ველში ჩაწერე `images/ფაილის-სახელი.jpg`. ინგლისური ტექსტები იმავე `name`-ით დაამატე `src/data/placesEn.js`-ში.

## ტექნოლოგიები და მათი არჩევის მიზეზი

- **HTML5**: სემანტიკური სტრუქტურა და ხელმისაწვდომობა.
- **CSS3** (Grid, Flexbox, CSS ცვლადები, მედია-მოთხოვნები): ერთი სტილის ფაილი, რესპონსიული განლაგება 320 პიქსელიდან დიდ ეკრანებამდე.
- **JavaScript და React**: საიტი კომპონენტებად არის დაყოფილი, ამიტომ ერთი და იგივე ბარათი გამოიყენება მთავარ გვერდზე, რჩეულებში და რუკაზე.
- **Vite**: სწრაფი გაშვება და აგება (`npm run dev`, `npm run build`).
- **Leaflet და OpenStreetMap**: უფასო რუკა API გასაღების გარეშე.
- **Open-Meteo**: უფასო ამინდის API გასაღების გარეშე.
- **Nominatim (OpenStreetMap)**: მისამართიდან კოორდინატების პოვნა.
- **Git და GitHub**: ვერსიების კონტროლი და გამოქვეყნება (`gh-pages`).

## პრობლემები და მათი გადაწყვეტა

- **ჰორიზონტალური გადაფარება პლანშეტზე და პატარა ტელეფონზე.** ავტომატური შემოწმებით ვნახე, რომ 768, 1024 და 320 პიქსელზე ზედა მენიუ ეკრანს სცილდებოდა. 1180 პიქსელამდე სრული მენიუს ნაცვლად ღილაკი ☰ ჩანს, ძალიან პატარა ეკრანზე კი არასაჭირო ღილაკები იმალება.
- **ორი ელემენტი ერთი და იგივე `id`-ით.** დამგეგმავის ველი და ამინდის სექცია ერთ `id`-ს იყენებდა. დამგეგმავის ველებს პრეფიქსი `plan-` დაემატა.
- **ერთმანეთზე გადაფარებული პინები რუკაზე.** ერთმანეთთან ახლოს მყოფი ადგილები (6 მაისის პარკი, აკვარიუმი, დელფინარიუმი) ერთმანეთს ფარავდა. რუკა ფილტრის მიხედვით ავტომატურად იზუმება.
- **გარე სერვისის ხარვეზი.** თუ ამინდის ან მისამართის სერვისი მიუწვდომელია, საიტი მომხმარებელს ტექსტით აცნობებს და დანარჩენი ნაწილი მუშაობს. თუ სურათი ვერ ჩაიტვირთა, ბარათზე ემოჯი რჩება.
- **დაბალი კონტრასტი.** Lighthouse-მა აღმოაჩინა ღია ნაცრისფერი ტექსტები, რომლებიც გავამუქე.
- **სიჩქარე.** სურათები 1200 პიქსელამდე დავამცირე, `loading="lazy"` დავამატე და რუკის ბიბლიოთეკა ცალკე ფაილად გავიტანე, რომ თავდაპირველი ჩატვირთვა მცირე იყოს.

## შემოწმებები

## შენიშვნა მონაცემებზე

მისამართი, საათები და ტელეფონი წყაროთი დადასტურებულია მხოლოდ აკვარიუმისა და დელფინარიუმისთვის (ბარათში წყაროს ბმულიც ჩანს). დანარჩენ ადგილებზე შეავსე `address`, `hours`, `phone` ველები `src/data/places.js`-ში, როცა გადაამოწმებ. ვიზიტამდე ფასები და განრიგი გადაამოწმე. Art Space-ის, აზროვნების აკადემიისა და Build-A-Bear-ის მისამართები, საათები და კოორდინატები ჯერ დამატებული არ არის.

## მისამართით ძებნა

„გამოიკვლიე ბათუმი“ სექციაში მისამართის ჩაწერისას საიტი OpenStreetMap-ის Nominatim სერვისით პოულობს კოორდინატებს და 5 კმ-ში მყოფ ადგილებს მანძილის მიხედვით აჩვენებს. ინტერნეტი აუცილებელია.

ადგილების კოორდინატები (`lat`, `lon` `src/data/places.js`-ში) მიახლოებითია. ზუსტად გასასწორებლად Google Maps-ში ადგილზე მაუსის მარჯვენა ღილაკით დააჭირე და პირველი ხაზი დააკოპირე (პირველი რიცხვი `lat`-ია, მეორე `lon`).
